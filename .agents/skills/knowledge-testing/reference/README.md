# reference/ — knowledge-testing artifacts

This folder is intentionally empty in the template. The team populates it during onboarding
by converting its source documents to Markdown (see the `knowledge-source-converter` skill).

The authoritative list of expected files — with the critical flag, refresh cadence and
responsible owner for each — is the artifact table in [`../SKILL.md`](../SKILL.md).

Record hosts and credentials as placeholders only — never real hostnames or secrets.

Files are written here by the onboarding agent (`!onboarding`), which converts the team's
source documents and delivers them as a merge request. Once uploaded, do not hand-edit them;
report errors to the responsible owner and re-run onboarding with a corrected source.
