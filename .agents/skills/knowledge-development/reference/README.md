# reference/ — knowledge-development artifacts

This folder is intentionally empty in the template. The team populates it during onboarding
by converting its source documents to Markdown (see the `knowledge-source-converter` skill).

The authoritative list of expected files — with the refresh cadence and responsible owner for
each — is the artifact table in [`../SKILL.md`](../SKILL.md).

Record configs, access details and secrets as placeholders only — never real hostnames or
credentials.

Files are written here by the onboarding agent (`!onboarding`), which converts the team's
source documents and delivers them as a merge request. Once uploaded, do not hand-edit them;
report errors to the tech lead and re-run onboarding with a corrected source.

Where the codebase contradicts a constraint stated here, that is drift worth reporting to the
tech lead — not permission to ignore the constraint.
